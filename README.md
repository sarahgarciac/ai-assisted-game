# 🎮 AI-Assisted Game: Plataforma Lúdica de Gramática (Claude AI & Web)

## Sobre o Projeto
Aplicação web interativa criada para resolver um desafio real de aprendizagem: ajudar alunos a fixar regras gramaticais e de redação de forma leve, visual e lúdica. 

O objetivo principal deste repositório é demonstrar o ciclo de **Engenharia de Prompt, visão de produto e prototipagem assistida por IA**, utilizando o modelo **Anthropic Claude** como ferramenta central no desenvolvimento da solução sem a escrita manual de código do zero.

🔗 **Acesse e jogue online:** [CLIQUE AQUI PARA JOGAR](https://sarahgarcia.github.io/ai-assisted-game/)

## 🧠 Meu Papel: 
Atuei no ciclo completo de idealização e especificação da solução:
* **Mapeamento de Necessidades:** Identificação das principais dúvidas gramaticais.
* **Engenharia de Prompt:** Formulação de instruções detalhadas no Claude para gerar a interface (HTML5/CSS3) e a lógica de verificação de respostas (JavaScript).
* **Design de Mecânicas:** Concepção do fluxo de pontuação, feedback imediato para os erros/acertos e navegação simples.
* **Validação Prática:** Testes de usabilidade aplicados diretamente no apoio ao ensino e solicitação de ajustes de comportamento para a IA.

## 🛠️ Tecnologias Utilizadas
* **Linguagens:** HTML5, CSS3, JavaScript (Estrutura e lógica geradas via IA)
* **Inteligência Artificial:** Anthropic Claude e Gemini (Geração de Código & Arquitetura Web)
* **Hospedagem & Ferramentas:** GitHub Pages, Git e VS Code
